## Objective
Implementar a classe BoundedList que ignora novos elementos adicionados após atingir max_len

## Parameters
- max_len

## Acceptance Criteria
- **AC-1**: A lista deve ignorar novos elementos adicionados após atingir max_len
- **AC-2**: O método to_list() deve retornar uma lista com os elementos corretamente limitados por max_len

## Tests
- **AC-1**: test_ac_1_ignore_excess_elements
- **AC-2**: test_ac_2_to_list_returns_correct_elements
