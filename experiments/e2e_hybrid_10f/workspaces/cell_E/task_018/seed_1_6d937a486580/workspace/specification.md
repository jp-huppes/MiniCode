## Objective
Implementar a função parse_int_list que converte uma string CSV em uma lista de inteiros

## Parameters
- csv_str

## Acceptance Criteria
- **AC-1**: A função parse_int_list deve converter corretamente uma string CSV em uma lista de inteiros
- **AC-2**: A função parse_int_list deve retornar uma lista vazia quando a string de entrada estiver vazia
- **AC-3**: A função parse_int_list deve ignorar espaços em branco na string de entrada

## Tests
- **AC-1**: test_ac_1_parse_int_list_conversion
- **AC-2**: test_ac_2_parse_int_list_empty_string
- **AC-3**: test_ac_3_parse_int_list_ignore_whitespace
